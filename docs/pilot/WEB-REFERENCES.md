## Proposed application

Keep workspace navigation and the message editor in normal HTML. Animate selection, panel entry and delivery-state changes with opacity and transform, approximately 140–220 ms. A message animation must advance only when its real state changes. Prefer a static state when prefers-reduced-motion is enabled.

Use the existing optional map for 3D work. Load it on request, stop rendering when hidden, retain a 2D list alternative and avoid camera movement during message composition. Benchmark the actual scene before choosing a rendering library or adding another dependency.

Next visual review should compare rendered desktop and narrow-width screenshots of Linear, Rive, Spline, Lusion and Bruno Simon. Assess task clarity, input latency, keyboard operation and motion reduction before selecting a pattern. The current research does not justify copying a full visual design.
